Tôi muốn tạo 1 tính năng Quản lý công việc / giao việc

- Tên tính năng: tasks (folder: src/features/tasks)
- Đường dẫn: /tasks
- Trong folder: src/features/tasks có:
  - components: chứa các component liên quan đến tính năng tasks.
  - services: chứa các dịch vụ liên quan đến tính năng tasks (làm việc với firebase firestore).
    - Thêm mới
    - Cập nhật
    - Xóa
    - Lấy danh sách tasks
    - Lấy chi tiết task

---

Cải tiến phần xem chi tiết task, dùng Sheet của shadcn UI.
